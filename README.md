# 🔱 Conversor de Moedas (Currency Converter)

> Uma aplicação web prática e intuitiva desenvolvida para realizar a conversão de valores entre diferentes moedas internacionais com cálculo rápido e feedback imediato na tela.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação prática de **JavaScript moderno (ES6+)**, tratamento de eventos, validação de campos e manipulação do DOM. A aplicação resolve uma necessidade frequente no dia a dia: converter montantes de dinheiro entre moedas como Real (BRL), Dólar (USD), Euro (EUR) e outras de forma simples e acessível.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da interface e seletores de moedas.
* **CSS3:** Estilização visual, layout centralizado e design responsivo.
* **JavaScript (ES6+):** Lógica matemática de conversão, manipulação do DOM e tratamento de eventos do usuário.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Seleção de moedas:** Permite escolher as moedas de origem e de destino para o cálculo.
* **Conversão instantânea:** Calcula e exibe o resultado formatado no padrão monetário correto.
* **Validação de entradas:** Garante que apenas valores numéricos válidos sejam processados.
* **Interface Responsiva:** Layout otimizado para navegação em computadores, tablets e smartphones.
